## รูปแบบที่ใช้

ทุกไฟล์ต้องมีครบ 5 อย่าง ไม่งั้นคนอื่นรันต่อไม่ได้

1. **ความเสี่ยง → เคสที่กัน** — บอกว่าแต่ละเคสมีไว้กันอะไรพัง ไม่ใช่เทสเอาจำนวน
2. **ทดสอบไปแล้วอะไร / ยังไม่ได้ทดสอบอะไร** — พูดตรง ๆ ว่าอะไรยังไม่ได้พิสูจน์
3. **ขั้นตอนที่ copy ไปรันได้จริง** — คำสั่งเต็ม พร้อมตัวอย่าง output ที่ต้องได้
4. **เกณฑ์ผ่านที่วัดได้** — ตัวเลข/จำนวนแถว ไม่ใช่ "ดูแล้วโอเค"
5. **ช่องกรอกผลจริง + defect log + ช่องเซ็นอนุมัติ**
